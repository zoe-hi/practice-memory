# 经验捕手｜原型业务清洗清单

> **状态：**P0 前端实现约束。本文不改变 UI 风格，只冻结哪些旧原型逻辑不能重新带入。
> 当前实现位于 `frontend/`，接口事实以 `frontend-api-contract.md` 和后端 OpenAPI 为准。

## 1. 全局替换

| 旧原型概念 | 正式 P0 概念 |
|---|---|
| 主题库 | 经验库 |
| 四个主题 | 单一儿童阅读活动经验库 |
| 支持经验 / 反例和矛盾 / 还不确定 | 普通经验卡；卡内保留七字段事实与反思 |
| 固定三问 AI 对话 | 后端动态复盘问题 |
| 本地 `SEED_CARDS` / `DRAFT` | 后端会话草稿与已确认经验 |
| 假录音时长、假波形、假“已记录”文本 | 浏览器真实录音状态与后端真实转写 |

## 2. 逐页改造

### Capture.tsx

- 保留：点击开始/再次点击结束的录音手势、文字输入入口、待整理与卡片确认的视觉流程；
- 改为：一次仅提交文字或一段语音；删除“继续补充一段”和多段录音列表；
- 改为：初始材料、AI 问题、草稿都来自后端会话；
- 删除：`DEBRIEF_QUESTIONS`、本地 `DRAFT`、本地 `onSaved` 作为数据事实。

### Themes.tsx

- 文件/组件可重命名为 `ExperienceLibrary`；
- 保留：经验卡列表、详情页、决策支持抽屉的视觉结构；
- 删除：`THEMES`、主题详情、主题计数、新手任务、分类色块；
- 改为：固定活动名的经验列表和一次性决策支持结果。

### Mine.tsx

- 保留：待整理、已整理、最近经验的视觉区块；
- 改为：后端会话列表与已确认经验列表；
- 页面名称继续使用“我的”，这是 MVP 的演示呈现决定；
- 删除：主题网络数量、固定的待整理数量，以及任何登录、个人数据隔离或真实账户能力声明。

### data.ts 与 ui.tsx

- 删除：`ModuleKey`、`MODULE_META`、`module` 字段、`THEMES`、主题图标和主题计数；
- 改为：后端七字段 `Experience` 类型的显示适配层；
- 经验卡标题仅可从后端字段截取生成供显示，不新增或假造经验结论。

## 3. 绝不带入正式前端的行为

1. 前端写死 AI 问题、AI 草稿、决策支持回复；
2. 前端把历史经验包装成“标准答案”；
3. 未经确认就把草稿显示为经验库正式内容；
4. 声称登录、个人隐私隔离或多人协作已经实现；
5. 本地数组作为经验库或待整理列表的唯一数据源。

## 4. 当前整合优先级

1. 优先用真实 DashScope 验证浏览器 WebM 转写、动态复盘和决策支持；
2. FakeAI 继续承担离线自动测试、文字 Golden Path 和真实服务不可用时的演示兜底；
3. 优先修复会阻断主链路的问题，不为登录、多租户、主题系统、路由框架或未来规模提前搭建基础设施；
4. “我的”仅表示当前 Demo 的个人视角，不等同于已实现身份认证或服务端个人过滤。
